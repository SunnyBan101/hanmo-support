개인정보처리방침 — HanMò (한묵)

앱 이름: HanMò (한묵)

발효일: 2026-04-25

최종 수정일: 2026-10-15 (Android 앱 추가)

연락처: sunnyban101@gmail.com

1. 한 줄 요약

HanMò는 사용자의 개인정보를 수집하지 않습니다. 모든 학습 기록은 사용자 기기 안에만 저장되며, 외부 서버로 전송되지 않습니다.

2. 적용 범위

이 방침은 iOS App Store와 Google Play에서 배포되는 HanMò (한묵) 앱(iOS·Android, 이하 "앱")에 적용됩니다. 앱 외부의 웹사이트·이메일 문의 등은 별도 표기에 따릅니다.

3. 수집하지 않는 정보

본 앱은 다음 정보를 수집하지 않습니다.

  • 이름, 이메일, 전화번호, 주소 등 개인 식별 정보
  • 광고 식별자(IDFA), 기기 지문(device fingerprint)
  • 위치 정보, 연락처, 사진, 카메라, 마이크
  • 학습 진도·점수·카드 통계 (서버 전송 0건)
  • 사용 패턴 / 분석(analytics) 이벤트
  • 충돌 보고(crash report) — 앱 자체적으로 수집·전송하지 않음

본 앱은 회원가입 / 로그인 / 계정 시스템을 두지 않습니다.

4. 기기에 저장되는 정보 (네트워크 전송 없음)

학습 경험을 위해 다음 정보가 사용자 기기 내부의 SwiftData 로컬 데이터베이스에 저장됩니다. 이 데이터는 외부로 전송되지 않으며, 사용자가 앱을 삭제하면 함께 삭제됩니다.

위 데이터는 모두 사용자 기기 1대 안에서만 처리됩니다. Apple iCloud·Google 계정 동기화나 앱 자체 클라우드는 사용하지 않습니다. (Android 앱은 시스템 자동 백업도 사용하지 않습니다.)

5. 백업 / 복원 시 처리

사용자가 직접 "백업" 기능을 실행할 때만 SQLite 파일이 생성됩니다.

  • 저장 위치는 사용자가 직접 선택합니다(예: iOS "파일" 앱·iCloud Drive, Android 파일 선택기의 다운로드 폴더·Google Drive 등).
  • 앱은 사용자가 고른 위치 외에 어느 곳에도 자동 복사·업로드하지 않습니다.
  • 사용자가 iCloud Drive 등 동기화되는 위치를 고른 경우, 해당 동기화는 운영체제·해당 클라우드 서비스의 책임 영역이며, 본 앱이 데이터를 직접 클라우드로 전송하는 것이 아닙니다.
  • 백업 파일을 다른 사람과 공유하면 학습 진도가 노출될 수 있으므로 사용자 책임 하에 관리해 주십시오.

6. 네트워크 사용

본 앱은 기본 동작에서 네트워크를 사용하지 않습니다(오프라인 100%).

  • 앱 다운로드 시점에 모든 학습 콘텐츠(HSK 1~9급 11,000 어휘 + 부수/획순 데이터)가 함께 설치됩니다.
  • 앱 실행 후에는 비행기 모드에서도 모든 학습 기능이 동작합니다.
  • 추후 콘텐츠 갱신을 위한 다운로드 기능이 추가될 경우, 그 시점에 본 방침을 갱신하고 사용자에게 고지합니다.

7. 트래킹 / 광고 / 제3자 SDK

  • 광고를 표시하지 않습니다.
  • App Tracking Transparency(ATT) 권한을 요청하지 않습니다.
  • Google Analytics, Firebase, Meta SDK, Adjust 등 어떠한 분석/광고/트래킹 SDK도 포함하지 않습니다.
  • 인앱결제(IAP) / 구독이 없습니다.

App Store Connect의 App Privacy 응답에서도 "Data Not Collected"로 신고합니다 (PrivacyInfo.xcprivacy의 NSPrivacyCollectedDataTypes = []).

9. 14세 미만 이용자 (COPPA / Apple Kids)

본 앱은 광고와 IAP를 포함하지 않으며, 개인정보를 수집하지 않으므로 14세 미만 이용자도 안전하게 사용할 수 있도록 설계되었습니다. App Store 연령 등급은 4+, Google Play 콘텐츠 등급은 전체이용가로 신청합니다.

다만 본 앱은 Apple "Kids Category"로 등록되지 않으며, 일반 Education 카테고리로 배포됩니다.

10. 사용자 권리

본 앱은 개인정보를 보유하지 않으므로 일반적인 의미의 "열람·정정·삭제 요청" 대상 데이터가 존재하지 않습니다. 다만 다음을 보장합니다.

  • 앱을 삭제하면 학습 기록을 포함한 모든 로컬 데이터가 함께 삭제됩니다(iOS·Android 표준 동작).
  • 직접 만든 백업 파일은 사용자가 고른 위치에 남으므로 필요하면 직접 삭제해 주십시오.

11. 보안

  • 모든 학습 데이터는 운영체제의 앱 전용 저장 공간에 보관되며, iOS 파일 보호(Data Protection — Complete Until First User Authentication 이상) 및 Android 앱 샌드박스·기기 암호화로 보호됩니다.
  • 별도의 인증 시스템이 없으므로 기기 잠금(Face ID / Touch ID / 지문 / 암호)을 사용하시기를 권장합니다.

12. 방침 변경

본 방침이 변경되는 경우, App Store·Google Play 업데이트 노트와 본 문서 상단 "최종 수정일"을 통해 고지합니다. 데이터 수집 정책에 실질적 변경이 있을 경우 앱 내에서 추가 동의를 받습니다.
